WHAT GAME MASSEG — ملفات الواجهة التجريبية
==============================================

الملفات:
- index.html: شاشة الدخول الإجباري وواجهة المحادثة.
- style.css: التصميم المتجاوب.
- app.js: وظائف تجريبية محلية وأسئلة حقيقة أو تحدي.
- ضع صورة الشعار المرفقة باسم logo.png داخل هذا المجلد.

التشغيل:
1) فك ضغط الملف.
2) ضع الصورة المرفقة في نفس المجلد وسمّها logo.png.
3) افتح المجلد في VS Code وشغّل index.html باستخدام Live Server، أو ارفع الملفات إلى استضافة HTTPS.

تنبيه أمان مهم:
هذه نسخة واجهة أمامية تجريبية وليست خدمة مراسلة جاهزة للنشر. الحسابات والأسماء والمحادثات مخزنة محليًا في المتصفح فقط، ولا توجد مصادقة حقيقية أو مزامنة بين الأجهزة أو تشفير طرف لطرف أو نسخ احتياطي بالبريد. لا تستخدم كلمات مرور حقيقية ولا ترسل معلومات خاصة. أزرار Google وApple تعرض توضيحًا فقط إلى أن يتم إعداد المصادقة الرسمية.

لتحويلها إلى منتج حقيقي:
- Firebase Authentication (البريد + Google) وSign in with Apple بإعداد رسمي.
- قاعدة بيانات وخادم بقواعد صلاحيات لكل محادثة.
- تحقق فريد من username على الخادم.
- تشفير طرف لطرف بمكتبة مدققة ومفاتيح آمنة.
- حذف الرسائل من الخادم بعد 12 ساعة عبر مهمة مجدولة/TTL، وليس فقط من المتصفح.
- نسخ احتياطي بموافقة واضحة من المستخدم، وعدم إرسال الرسائل الخاصة إلى بريد ثابت دون موافقة.
